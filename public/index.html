How it works

      
LatexGen converts plain-English math and equation screenshots into LaTeX inside your browser. There is no upload step: the models are downloaded once, cached, and run on your own device. That is why it is free without limits, and why it keeps working offline.

      
    
        
  1. A specialist model answers first. A 220M-parameter model fine-tuned only for text-to-LaTeX handles single equations in well under a second, on any device, no GPU needed.
    2. 
        
  2. Every result is checked. The LaTeX must parse, and the numbers and concepts you typed must actually appear in it. Failures trigger up to five self-repair attempts with the exact error fed back to the model.
    3. 
        
  3. Harder input climbs a ladder. Prose passages and multi-line input go to an on-device language model when your machine can run one, or to an optional server model. Screenshots use two on-device OCR models chosen by benchmark.
    4. 
      

      
Why it is free

      
Paid converters forward your text to a rented cloud model and meter it: typically $9–19 a month for a few hundred conversions, with 10 free ones to hook you. Your laptop already has the compute. LatexGen just uses it, so there is nothing to meter and nothing to charge for.

Questions

      
Does it really not upload anything? Text and images are processed in the tab. Open your browser's network panel while converting: the only requests are for model files. The one exception is the optional server model, which is off by default and clearly labelled when it is used.

      
How big is the download? Quick mode is about 340 MB of models, downloaded once. Full mode adds an on-device language model sized to your machine (1.4–6 GB), fetched in the background while you work.

      
Can it check LaTeX I already have? Yes. Switch the input to Check LaTeX, paste your code, and it is parsed, rendered, and repaired if it does not compile.

      
Which models? IntelliTeX for text, Texo and Texify for images, Qwen3 models via WebLLM for complex input. The benchmarks page shows how each was chosen.
